# Candy Mapper — Manual Testing Mini Project

## Project Overview
This project focuses on manually testing the Candy Mapper website to evaluate its functionality, input validation, usability, and user interactions.

## Testing Activities
- Prepared application features and requirements.
- Created a test plan and manual test cases.
- Mapped requirements to test cases using an RTM.
- Executed test cases and documented actual results.
- Recorded defects and testing observations.
- Prepared test execution and summary reports.

## Testing Types
- Functional Testing
- Positive and Negative Testing
- Input Validation Testing
- UI and Usability Testing
- Regression Testing, where applicable

## Application Under Test
https://candymapper.com/

## Tools Used
- Web Browser
- Microsoft Excel
- Git and GitHub

## Project Deliverables
The Excel workbook contains:
- Application URL
- Features
- Requirements
- Test Plan
- Test Cases
- Requirement Traceability Matrix (RTM)
- Bug Report
- Test Execution Report
- Test Summary Report

## Project Objective
To verify application behavior against documented requirements, identify defects, and maintain traceable manual testing documentation.
